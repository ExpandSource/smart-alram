# Smart Alarm

브라우저에서 사용하는 학교 시간표·일정 알람입니다.

**접속:** https://expandsource.com/smart-alram/

GitHub Pages 주소 `https://expandsource.github.io/smart-alram/`도 계정에 연결된 도메인으로 이동합니다.

- 알람 시간·이름·활성화 여부 편집, 5분 미루기
- 브라우저에서 합성하는 8가지 알람음과 볼륨·반복 설정
- Light / Dark 테마 및 모바일 화면 지원
- 시작·종료 한도, 수업·쉬는 시간, 교시 수로 시간표 자동 생성
- 식사·특별 휴식 추가, 시간표 미리보기와 종료 한도 초과 검사
- 여러 시간표를 이름 붙여 저장·불러오기·삭제
- 알람 설정과 테마는 기기별 브라우저 localStorage에 저장

처음 접속한 뒤 소리 활성화 버튼을 누르세요. 알람을 사용하려면 탭을 열어두고 기기의 절전을 해제해야 합니다. 백그라운드에서는 브라우저 정책에 따라 알람이 지연될 수 있습니다.

## 시간표 만들기와 보관

1. **내 시간표 → 시간표 자동 채우기**를 열고 시작 시간, 종료 한도, 수업·휴식 길이, 교시·타임 수를 입력합니다.
2. 필요한 경우 **식사·특별 휴식**을 추가합니다. 예를 들어 4교시 뒤 점심 60분을 지정하면 그 위치의 일반 쉬는 시간을 대신합니다.
3. 미리보기에서 끝나는 시각과 남는 시간을 확인하고 **이 시간표 적용**을 누릅니다. 기존 알람 목록을 바꾸기 전에 확인합니다.
4. 시간표 이름을 입력하고 **현재 목록 저장**을 누릅니다. 이후 직접 편집한 시간·이름·켜기/끄기 상태도 저장할 수 있습니다.
5. 저장한 시간표를 선택해 **불러오기**를 누르면 알람 목록과 생성 조건이 복원됩니다. 소리 설정은 유지됩니다.

같은 시각의 수업 종료·식사 시작 등은 이름을 합쳐 한 번만 울립니다. 종료 한도를 넘기면 적용할 수 없으며, 남는 시간은 비워둡니다. 자정을 넘기는 시간표는 지원하지 않습니다. 저장한 시간표는 같은 사이트의 같은 브라우저에서만 유지되며 기기 간 동기화되지 않습니다.

## 로컬 실행

```sh
npm ci
npm run dev
```

계산 로직 검증: `npm test`

## 배포

`main`에 push하면 GitHub Actions가 빌드한 `dist`를 GitHub Pages에 자동 배포합니다. 저장소 Settings → Pages의 Source는 GitHub Actions를 사용합니다.

```sh
npm run build
npm run preview
```

백엔드나 데이터베이스 없이 정적 파일로 실행됩니다. 글꼴은 Google Fonts에서 불러옵니다.
